# Werwolves Narrator Help

This is a project for [Hackclub Midnight](https://midnight.hackclub.com/)

Currently, German-only in all print statements, might be extended later on. Helps you remember everything from the night of werwolves. It automatically does everything for you and collects the deaths you need to proclaim.

> Note: This is not a finished product yet, but it works as a first prototype and will be tested and possibly improved later on.

# Installation

Run the binary in the terminal (Linux only)
